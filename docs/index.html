Using the decks

  • On a laptop: → and ← move between slides, O shows them all, F goes full screen.
  • On a phone: the slides stack into one scrolling page.
  • Presenting: N shows speaker notes and P opens a presenter window with notes, a timer and the next slide.
  • Everything runs in your browser. Nothing you type in a demo is sent anywhere.
